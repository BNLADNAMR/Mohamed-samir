# نظام متابعة الشفتات وأداء المندوبين (Shift Tracker)

نظام ويب متكامل باللغة العربية (`RTL`) لإدارة الحضور اليومي للمندوبين، جدولة الشفتات الشهرية، واحتساب مؤشرات الأداء والالتزام الفعلي بدقة مع جاهزية كاملة لميزة **الوضع الداكن والفاتح (Dark / Light Mode)** وتصدير تقارير **Excel / CSV** والنسخ الاحتياطي **JSON**.

---

## 📦 الملفات الجاهزة للنشر المباشر عبر GitHub Web بدون أخطاء

تم إنشاء وتجهيز جميع ملفات الإنتاج المدمجة مسبقاً داخل المشروع لتعمل بأي طريقة تفضلها عبر متصفح GitHub Web:

### 1. مجلد `github-web-upload/` (جاهز للرفع المباشر عبر `Add file -> Upload files`)
إذا أردت رفع الموقع يدوياً من المتصفح إلى مستودع GitHub ليعمل من الجذر `/(root)` مباشرة بدون أي إعدادات معقدة:
- ارفع الملفات الثلاثة الموجودة داخل مجلد **`github-web-upload/`**:
  - `index.html` (يحتوي على النظام بالكامل والوضع الداكن مدمجاً بداخله بدون أي ملفات خارجية).
  - `404.html` (لمنع أخطاء الصفحات غير الموجودة على الرابط).
  - `.nojekyll` (لمنع تعارض معالج GitHub الافتراضي).
- من إعدادات المستودع **Settings → Pages** اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.

### 2. مجلد `docs/` (جاهز للتفعيل عند تصدير المشروع كاملاً إلى GitHub)
إذا صدّرت المشروع بالكامل كما هو إلى مستودع GitHub:
- افتح **Settings → Pages** في مستودعك على GitHub Web.
- اختر **Source: `Deploy from a branch`**، وحدد الفرع `main` والمجلد **`/docs`** ثم اضغط **Save** (أو اختر **Source: `GitHub Actions`** ليعمل ملف البناء التلقائي `.github/workflows/deploy.yml`).

## ✨ المميزات الجاهزة والمفحوصة
- **الوضع الداكن والفاتح (Dark Mode)**: يعمل فور فتح الصفحة بدون وميض، مع زر تبديل فوري وحفظ تلقائي للتفضيل في المتصفح، واستعادة خلفية بيضاء تلقائياً عند الطباعة الورقية.
- **حسابات دقيقة ومتسقة**: دعم الشفتات الليلية بعد منتصف الليل، خصم الاستراحات، ومطابقة تامة بين ألوان الخلايا وملخص الأداء وتقرير Excel.
- **إدارة شاملة للمندوبين**: إضافة، تعديل، تبديل الحالة (نشط / موقوف)، حذف آمن، وتهيئة 100 مندوب تجريبي بضغطة زر.
- **التصدير والنسخ الاحتياطي**: تصدير جدول الشهر بصيغة `CSV / Excel` بالترميز العربي السليم (`UTF-8 BOM`)، مع استيراد وتصدير نسخ `JSON` الكاملة.
